# The World in One Day — 17 November 2026

A one-image summary of Tuesday 17 November 2026's world news, drawn
programmatically with Pillow (`draw.py`) as a newspaper front page:
the Kerch Bridge struck again, tankers hit by mines off Hormuz, Trump
in Manila with a Xi–Trump–Putin meeting set, Japan scrambling jets,
and the West urging Israel to open Gaza's crossings — plus the day's
other headlines in a ticker.

Entry for the [news-image-20261117 bounty on make.fun](https://make.fun/bounty/news-image-20261117).

## How it runs

`main.py` (Python 3, standard library only, no network) copies the
shipped `entry.png` (1024×1024, 107,266 bytes) to
`$MAKEFUN_OUTPUT_DIR/entry.png`, so both grading runs write identical
bytes. Regenerate the image with `python3 draw.py` (needs Pillow).
